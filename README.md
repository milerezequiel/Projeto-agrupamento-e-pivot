# Análise – SINASC RO 2019

Este projeto apresenta uma análise simples do conjunto de dados SINASC_RO_2019, com informações sobre nascimentos no estado de Rondônia no ano de 2019.


## Uso de groupby

Operações de agregação (média, mínimo, máximo, mediana, desvio padrão e variância)

Criação de faixas (latitude, área e altitude)


## Uso de pivot_table

Construção de gráficos

Foram feitas comparações entre municípios com diferentes características geográficas e socioeconômicas, como IDH, IFDM e PIB.

Ao final, foi possível observar algumas diferenças entre os grupos analisados, principalmente em relação à idade média das mães e peso dos bebês.

O foco principal do trabalho foi aplicar os conceitos aprendidos em aula e entender melhor como organizar e resumir dados utilizando o pandas.
